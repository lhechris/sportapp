# Paramètres d'équipe 1/2

## nom
le nom de l'équipe

## lien d'invitation du groupe Whatsapp
pour envoyer le message de convocation.

Dans l'application Whatsapp _paramètres->info groupe->inviter via un lien ou un code QR_

## Message de convocation
c'est le message généré dans les matchs. Les tags suivants seront remplacés :

- %SELECTION% : la liste des joueurs sélectionné

- %NONSELECTION% : la liste des joueurs non sélectionné

- %JOURMATCH% : la date et heure du match _ex: samedi 08 août_.

- %RENDEZVOUS% : le texte définie dans le champ rendez vous du match.
